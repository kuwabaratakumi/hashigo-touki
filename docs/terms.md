# 情報の集め方メモ（2026-11-14 時点）

| 情報源 | 扱い | 理由 |
|---|---|---|
| 各陶器市の公式サイト・主催者（組合、商工会議所、観光協会、自治体） | 人が読んで日程を `data/dates.csv` に書く。自動取得はしない | サイトの作りが主催者ごとに違い、更新も年1〜2回なので、手作業で足りる |
| 巡回型の主催者（全国大陶器市振興組合など） | 同上。会場ごとに1行 | 主催者のページ1つで全会場を拾える |
| イベント情報サイト（るるぶ、トレたび、いこーよ、tabi-mag など） | 新しい陶器市を見つける・日程を確かめるために読む。文章や写真は転載しない | 掲載するのは日付・場所などの事実だけ。`source` に確認元のURLを残す |

- 写真は使わない（公式サイトへのリンクで案内する）
- 説明文は自分の言葉で短く書く。確認元の文章をそのまま写さない
- 「例年どおりなら」の日付は、過去の開催日から閲覧時に計算している（どこかから取得した日程ではない）
